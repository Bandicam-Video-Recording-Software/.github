## 🧠 Overview

Bandicam is a Windows recording application for capturing desktop activity, gameplay, and video from connected devices. It allows users to record selected screen areas, full-screen sessions, individual applications, and supported external video sources.

With configurable recording settings, microphone input, webcam overlays, and hardware-accelerated encoding, Bandicam is suitable for creating tutorials, recording gaming sessions, preparing presentations, and saving on-screen activity. Its straightforward interface helps users manage capture settings and recordings from one place.

## Additional Information for Windows Users

Bandicam provides several recording modes, allowing users to choose a capture method suited to their activity. Screen Recording is useful for tutorials and desktop demonstrations, Game Recording is intended for supported games, and Device Recording can be used with compatible external video sources.

Recording performance depends on the selected resolution, frame rate, encoding method, and available hardware. Higher-quality captures require additional storage, while hardware encoding may help reduce processing demands on supported systems.

For clearer recordings, check the selected microphone and system audio devices before starting. When capturing games or applications, choosing the correct recording mode and adjusting the capture area can help avoid unwanted content or missing audio.
